# Vitamin C Brightening Serum — Product Sheet

## Overview

A lightweight daily serum with 15% stabilized vitamin C (ascorbyl glucoside) for a brighter, more even-looking complexion. This sheet (version 2) replaces the 2025 sheet and is effective from 2026-03-01.

## Key Ingredients

- **15% ascorbyl glucoside** — stabilized vitamin C derivative, less irritating than pure L-ascorbic acid.
- **3% niacinamide** — supports an even-looking skin tone.
- **Ferulic acid + vitamin E** — antioxidant support.
- **Hyaluronic acid** — lightweight hydration.
- Fragrance-free, vegan, cruelty-free.

## Skin Types

- **Best for:** normal, combination, oily and dull-looking skin.
- **Suitable for:** sensitive skin after a patch test (stabilized derivative, pH 5.5).
- **Not recommended:** on freshly exfoliated skin in the same routine as strong AHA peels.

## How to Use

1. Apply 3–4 drops to clean, dry skin every morning.
2. Follow with moisturizer.
3. Always finish with sunscreen (we recommend SPF 50 Daily Fluid).
